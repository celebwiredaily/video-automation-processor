# Example project (~5 minutes)

A production-shaped project assembled from the reference footage.

```bash
python -m video_pipeline render examples/sean-connery-5min
python -m video_pipeline validate examples/sean-connery-5min/output/final.mp4 \
    --project examples/sean-connery-5min

# publish the validated render to Google Drive
export GOOGLE_DRIVE_CREDENTIALS=/secure/path/service-account.json
python -m video_pipeline render examples/sean-connery-5min --upload
```

Assets in `assets/` are generated by `tools/build_example_project.py` and
are not committed. Point `voiceover`, `captions/segments.json` and
`timeline.yaml` at your own material to reuse this as a template.
